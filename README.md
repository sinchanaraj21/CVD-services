# CVD — Cardiovascular Disease Prediction System

This project predicts cardiovascular disease risk using Machine Learning.

## Tech Stack
- React frontend
- Spring Boot backend
- FastAPI ML service (XGBoost + SHAP)
- PostgreSQL database

## How it works
Frontend → Backend → ML Service → Database → Backend → Frontend

## Run locally
1. Start PostgreSQL
2. Start ML service (port 5001)
3. Start backend (port 8080)
4. Start frontend (port 3000)
