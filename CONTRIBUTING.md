# Contributing

Contributions are welcome! Here's how to get started:

## Setting up

1. Fork the repo and clone your fork.
2. Follow the **Local Development** steps in `README.md`.
3. Create a feature branch: `git checkout -b feat/your-feature`.

## Guidelines

- Keep PRs focused — one feature or fix per PR.
- Write clear commit messages (`feat:`, `fix:`, `docs:`, `refactor:`).
- Don't commit `.env`, `model.pkl`, or any build artifacts (`target/`, `build/`, `node_modules/`).
- If you retrain the model, update the metrics table in `README.md`.

## Reporting issues

Open a GitHub Issue with a clear description and steps to reproduce.
